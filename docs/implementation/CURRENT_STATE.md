## F04/F13 asset semantics, object library and UI repair — 26 October 2026

Working-tree changes (not committed; this folder is still not a git checkout) close the "figures and formulas never reach the deck" gap and add reusable visual objects:

- **Assets are interpreted by default.** CLI generation now defaults to `--asset-mode structured`, so `enrich_assets` → `interpret_assets` (multimodal LLM call per usable asset, original-context packet, baseline validation) → `asset_insights_to_units` runs on every generation. One unreadable asset records explicit partial coverage instead of aborting the whole deck. The Studio sends the same option and exposes a "Source visuals" control.
- **Selected visuals are actually displayed.** `attach_asset_candidates` links an asset-derived unit to its `origin_asset_ids`, and additionally attaches one section-matched figure/formula per slide when the planner omitted it (table-led slides are skipped); the asset's accepted insight unit and its chunk are added to the slide scope so its semantic meaning can reach the text. `pipeline/visual_placement.py` then guarantees placement: it fills an image/formula region, or remaps a text-only slide onto `IMAGE_WITH_TEXT_RIGHT` while preserving its text; it never replaces existing text or a table. Formula assets are rendered as their source crops.
- **Six predefined objects** are first-class IR2 content types: `card`, `metric_card`, `callout`, `quote`, `chips`, `compare`. `renderers/base.py` expands each into ordinary scene primitives (background shape + text), so both renderer backends consume the same scene contract; the layout catalog allows them as alternatives in card/grid/process/metric/comparison/quote/closing layouts. Theme tokens supply surface/border/text colours.
- **Geometry:** single text/object boxes are capped at measured need (no stretched empty cards), a single object row is capped and top-aligned, and non-structural candidate rows now include horizontal, vertical and 2×2 card options. Applies to ordinary bullet slides too (published IR2 still passes the gate).
- **UI repair:** the parse cache created staging directories with `tempfile.mkdtemp` (mode 0700); under the Windows sandbox that directory is unwritable, so every Studio parse failed with `PermissionError: source_snapshot.bin`. `core/artifacts.py` now allocates a normally-created `.candidate-*` directory. PowerPoint export used `WithWindow=False`, which makes PowerPoint refuse to open any deck containing a raster image; it now opens with a window. Render work directories moved out of system temp into the service root. Studio job tracking now works for jobs resumed from `GET /api/jobs` (the previous code keyed the job map by an undefined `job_id`).
- **Verification (local, no live provider):** eight tests in `tests/test_visual_objects_f13.py` pass when invoked directly (the pytest temp-root ACL remains unusable in this sandbox); the end-to-end fixture test `tests/test_asset_visual_flow_f04.py` proves structured interpretation → IR1 asset unit → deterministic selection → image placement → gate pass on `assets.docx`; the existing layout/fitting/theme suites were run manually with the same two-environment caveat: 14 layout/fitting cases and 7 pure theme cases pass.
